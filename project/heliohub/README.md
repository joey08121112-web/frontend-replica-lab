# 沐光 HelioHub · 原创产品网站（Project C 毕业作品）

这是你的项目，不是课程给你的模板。课程平台（learn.html）只负责 Brief、决策记录、
QA 与 Review 流程；**代码写在这里，浏览器直接打开这里。**

## 文件职责

| 文件 | 职责（详见 learn.html 的 Client Brief） |
|---|---|
| index.html | Home / 产品体验 |
| calculator.html | 节能计算器（核心交互，Teaching Model 公式见 Brief） |
| plans.html | 资费与方案对比 |
| survey.html | 预约上门勘测（表单——需要你先自学表单知识） |
| support.html / privacy.html | 二级页 |
| styles.css / main.js | 你的系统，你的架构 |
| assets/ | 你选择使用的素材（课程素材包在 assets/images/helio/，按需复制到这里） |

## 如何运行

双击 index.html 即可（file:// 打开，无需服务器）。编辑用任意编辑器。

## 哪些决定是你自己的

信息架构 · 语义结构 · 布局方式 · 断点 · 配色与字体 · 计算器交互形态 ·
表单实现 · JS 架构。

starter 只提供文件骨架与极简 reset——**没有任何设计已经被决定**。
每一个决定写进 learn.html 的 Decision Log，并准备在 Final Defense 中辩护。
